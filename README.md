# 3d-carshop

Realistik 3D avtomobillar namoyishi, PBR bo'yoq konfiguratori, interaktiv faralar, dvigatel ovozi sintezi va muhandislik portlash (exploded view) animatsiyasiga ega ultra-zamonaviy veb-ilova.

## 🚀 Imkoniyatlar

- **8 ta haqiqiy 3D GLB model**:
  - Ferrari 458 Italia (4.5L V8 Atmosfera)
  - BMW M3 E30 Sport Evolution (DTM afsonasi)
  - Mercedes-AMG G 63 Geländewagen (V8 Biturbo)
  - BMW M2 Coupe G87 Competition (Twin-Turbo)
  - Tesla Model 3 Performance (Dual Motor AWD)
  - Tesla Cybertruck Cyberbeast (Tri-Motor EV)
  - Lamborghini Countach LPI 800-4 Wedge V12
  - Aero Project Apex Hypercar (1100 HP Track Spec)
- **Kuzov bo'yog'i konfiguratori**: Zavod ranglari va 3 xil qoplama (Metallik, Yaltiroq, Mat).
- **Interaktiv faralar**: Ksenon faralar va neon gabaritlarni yoqish/o'chirish (sahna poliga haqiqiy yorug'lik tushadi).
- **Detallarga sochish (Exploded View)**: Avtomobil detallarini (g'ildiraklar, kapot, eshiklar, tom, spoyler) silliq sochib tashlash va qayta yig'ish.
- **Dvigatel akustikasi (Sound Engine)**: Web Audio API orqali V8, V12, Turbo va EV motorlarining haqiqiy tovush sintezi hamda interaktiv tahometr (8 200 RPM gacha).
- **6 ta kinematik kamera rejimi**: 360° Erkin, Old, Yon, Orqa, Tepadan va G'ildirak yaqinidan.
- **Avtomobillarni taqqoslash (VS Compare)**: Istalgan 2 ta mashinani texnik parametrlarini solishtirish.
- **100% Ultra-Responsive Moslashuvchanlik**: Smartfonlar (iPhone, Android), planshetlar (iPad) va katta monitorlarga to'liq moslashgan layout, mobil gamburger menyu, sensorli sensor (touch) optimallashuvi va safe-area qo'llab-quvvatlashi.

## 🛠 Texnologiyalar

- **React 19**
- **Three.js** + **@react-three/fiber** + **@react-three/drei**
- **Vite 6**
- **Web Audio API** (tovushlar sintezi)
- **Khronos PBR Next** (Clearcoat, Transmission, Emissive)
- **CSS3 Modern Glassmorphism & Responsive Flexbox/Grid**
